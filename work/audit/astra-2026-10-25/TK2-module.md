# TK2 module evidence

Reviewed design e0b802a. Commands: `python3 checks/jlc_rotation.py --board module -v` (cwd work), pcbnew pad/net inspection, CSV comparison and SHA256 comparison. No staging regeneration needed: existing outputs were present. See TK2-rotation.log.

- MEASURED: 57/57 order CPL rows agree with the cached EasyEDA fit. Q1 PCB origin (99.695,76.962) mm, rotation 180; gate pad1 (103.895,79.242), drain/tab pad2 (97.595,76.962), source pad3 (103.895,74.682). Order CPL is (100.606,-76.962), rotation 0; +0.911 mm X origin correction. Thus the tab remains on the left, while leads remain on the right. This uses the cached footprint transform, not an independent JLC machine preview. ST's [VND14NV04 datasheet](https://www.st.com/resource/en/datasheet/vnd14nv04.pdf), package/block diagrams, identifies tab as drain; board pad2 connects the heater return, pad3 the ground return. No reversed switch established.
- DOCUMENTED: [Torex XC6206 ETR03005-009](https://product.torexsemi.com/system/files/series/xc6206.pdf) p3 explicitly lists **SOT-23 1 VSS, 2 VOUT, 3 VIN**, top view. MEASURED: U9.1 GND, .2 +3V3, .3 +5V. The EasyEDA name override is correct; this closes the previously UNKNOWN datasheet question.
- DOCUMENTED: staged BOM R10 is C2087389, value61.9,0603, replacing C23092. [Panasonic ERA family specification](https://industrial.panasonic.com/cdbs/www-data/pdf/RDQ0000/ast-ind-171290.pdf) p7 gives ERA3AEB 0603,0.1W,0.1%,25ppm/K. CALCULATED: at a 60 K change, TCR contributes at most 0.15%; conservatively adding initial tolerance gives 0.25% resistor error. Pump-current gain error has corresponding magnitude (and inverse sign for shunt conversion). This is better than upstream's 1% initial part; it is not a total controller accuracy guarantee. A 3mA illustrative pump current dissipates I²R=0.557mW, far below0.1W. Actual complete sensor operating envelope not independently qualified here.
- DOCUMENTED: [Yageo exact C3 specification](https://yageogroup.com/download/specsheet/CC0402KRX7R9BB333) gives33nF,10%,50V,X7R,0402. MEASURED from PCB nets: C3 and R33 are both across U1A output/inverting input, so C3 shapes pump amplifier feedback. CALCULATED R33=10k gives feedback impedance pole 1/(2pi*10k*33n)=482Hz. X7R substitutes the same nominal capacitance with more predictable temperature behavior than Y5V; no new topology or nominal pole change. This is a reasonable substitution, not proof of the complete upstream loop's phase margin.
- MEASURED: module Gerber ZIP SHA256 matches upstream revC exactly: `7b7f18362efd8d803eaf3d87285cf13fe40bb1a2ea682c3d88a1543b58621101`. This proves copying, not independent equivalence of all Gerber shapes to the current PCB.
